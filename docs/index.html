Warrant

A gateway that serves a paid API only to AI agents with an accountable human behind them. This is an unedited run against Concordium testnet (90 seconds, no sound).

What you see: an agent with no badge, a made-up badge and a copied badge is refused; the agent that owns its badge pays over x402 and is served; the third request hits the owner's limit; the audit log head is written on chain.
